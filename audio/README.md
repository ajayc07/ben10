# Transformation sound

Drop the Omnitrix selection sound here as:

```
omnitrix-select.mp3
```

It's picked up automatically by `script.js` (`TRANSFORM_SOUND_SRC`) — no code changes needed.
Keep it short (roughly 0.3–1s) so it matches the card charge-up + reveal timing.
If it's missing, the site falls back to a synthesized power-up tone.
